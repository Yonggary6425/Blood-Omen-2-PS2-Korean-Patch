블러드 오멘 2 (PS2 북미판 SLUS-20024) 한글패치 v1.0
by Yonggary6425 (용가리) - 본 한글패치는 개인이 제작한 비공식·비상업적 팬 한글패치입니다.

[준비물]
  - 원본 ISO: Blood Omen 2 - The Legacy of Kain Series (USA) / SLUS-20024
    크기 4,140,236,800 바이트, MD5 d2b7f79118b1b881de5c999be826872d
  - 빈 디스크 공간 약 3 GB

[적용 방법]
  A) Windows (기본 PowerShell 사용 - 별도 설치 불필요)
     1. 원본 ISO를 "패치하기.bat" 위에 끌어다 놓습니다.
     2. 선택 패치 두 가지를 차례로 물어봅니다. Y 또는 N 을 누르고 Enter. (그냥 Enter 는 N)
     3. 같은 폴더에 "원본이름 (Korean).iso"가 생깁니다. (원본 ISO는 수정하지 않음)
        "완료! (한글패치 ...)"가 나오면 성공입니다. 1~2분 걸립니다.
  B) Python (macOS/Linux)
     python3 patch.py "원본.iso"                       물어봅니다
     python3 patch.py "원본.iso" --korean-only         한글패치만
     python3 patch.py "원본.iso" --wide --controls     선택 패치 지정

  - 한글패치는 항상 적용됩니다. 선택 패치는 고른 것만 적용됩니다.
  - 선택을 바꾸려면 원본 ISO에 패처를 다시 실행하세요. (패치본에 덮어 적용하지 마세요)
  - 동영상 자막은 bo2_kor_movies.bin 이 같은 폴더에 있으면 묻지 않고 적용됩니다.
    빼고 싶으면 이 파일을 지우고 실행하세요.
  - 적용 전에 원본의 MD5를, 적용 후에 결과를 검사합니다.

[선택 패치]
  1) 16:9 와이드 화면
     시야를 좌우로 넓혀 16:9로 그립니다. 에뮬레이터·TV를 16:9로 맞춰야 합니다.
     (4:3으로 두면 그림이 좌우로 눌려 보입니다)
  2) 조작 체계 변경
     왼쪽 스틱 = 앞뒤 이동 + 좌우 게걸음, 오른쪽 스틱 = 시점 회전.
     (원본은 왼쪽 스틱 좌우가 회전입니다)
  둘 다 고르지 않으면 화면 비율과 조작은 원본 그대로입니다.

[주의]
  - 세이브 스테이트로 불러오면 이전 글꼴·문장이 보일 수 있습니다. 메모리 카드 세이브로 불러오세요.

[한글화 범위]
  - 메뉴·시스템 문구, 조작 안내문, 장 제목 화면
  - 컷신 대사 자막 (원본 북미판에는 자막이 없음)
  - 자막 자료가 없던 음성 1,051줄 (전투 중 외침, 보스 대사 등)
  - 동영상 자막: 새 게임 글 두루마리, 도입 영상, 결말 영상, 예고편 2편
  - 배경 간판·포스터 22장
  - 한글 글꼴 844자, 타이틀 화면, 한글화 크레딧 화면, localization by yonggary 표기
  - 음성은 영어 그대로입니다.

[알려진 사항]
  - 부팅 때 나오는 CG 도입 영상, 예고편 한 편, 제작진 명단에는 한글 자막이 없습니다.
  - 자막을 넣은 영상은 다시 인코딩되어 원본보다 화질이 다소 낮습니다.
  - 실제 화면으로 확인한 범위는 메뉴와 제1장 초반입니다. 실기에서는 확인하지 않았습니다.

[파일]  (모두 같은 폴더에 두세요)
  패치하기.bat / patch.ps1 : Windows 적용기
  patch.py                 : Python 적용기
  bo2_kor.bin              : 한글패치 데이터
  bo2_opt_wide.bin         : 선택 패치 - 16:9 와이드 화면
  bo2_opt_controls.bin     : 선택 패치 - 조작 체계 변경
  bo2_kor_movies.bin       : 동영상 자막 데이터 (있으면 자동 적용)
